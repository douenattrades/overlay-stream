# overlay-stream

Overlay de OBS con los resultados de la semana (L M X J V), el total y el winrate.

## Ponerlo en OBS
1. **+** → **Navegador**
2. Desmarca **Archivo local**
3. URL: `https://douenattrades.github.io/overlay-stream/?canal=douenattrades&chatroom=134182507`
4. Ancho **1920**, alto **1080** (ocupa toda la pantalla; el recuadro se coloca solo abajo a la izquierda)

## Comandos en el chat de Kick (solo tú y tus mods; el overlay lee el chat cada 4 s)
| Comando | Qué hace |
|---|---|
| `!pnl -300` | Pone el resultado de hoy en −300$ |
| `!trade +150` | Suma +150$ al resultado de hoy (úsalo después de cada trade) |
| `!pnl x -1000` | Pone el resultado de otro día (l, m, x, j, v) |
| `!pnl borrar` | Borra el resultado de hoy |
| `!pnl reset` | Borra todo lo puesto por chat esta semana |

Cada lunes empieza la semana de cero sola.
